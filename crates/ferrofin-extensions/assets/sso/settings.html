Single Sign-On

Let users sign in with an OpenID Connect identity provider, such as Authentik, Authelia, Keycloak or Pocket ID. Changes apply at once.

Public URL

The address users reach this server at, base path included, such as https://media.example.org. Each provider's callback URL is built on it. When it is empty, the Published server URL in Ferrofin Settings is used.

OIDC providers

1 to 32 lowercase letters, digits or hyphens, such as "authentik". It is part of the callback URL, so it cannot be changed once the provider is saved.
The name users see on the sign-in button.
The provider's issuer, whose discovery document is at /.well-known/openid-configuration under it, such as https://auth.example.org/application/o/ferrofin/.
Warning: only for an identity provider on a network you trust. Over http, sign-in codes and tokens travel unencrypted and can be read or changed on the way.
